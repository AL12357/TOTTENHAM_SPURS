# Tottenham Hotspur Website

A simple multi-page website about **Tottenham Hotspur Football Club**, also known as **Spurs**. It was built with plain HTML and CSS as a front-end practice project.

## About the Club

Tottenham Hotspur is a professional football club based in North London, England. Founded in 1882, the club plays in the English Premier League and is known for its navy and white colours and the cockerel emblem. Spurs play their home matches at the Tottenham Hotspur Stadium.

## About the Project

The site presents the club's home page and its history, including the trophies it has won. The pages are linked together through a shared navigation bar, and the design follows the team's colours.

### Pages

| Page | Description |
| --- | --- |
| `index.html` | Home page with the club logo and navigation |
| `tottenham.html` | History of the club and the variety of trophies it has won |

## How to Run

1. Clone the repository:
   ```
   git clone https://github.com/oolakenneth6/tottenham.git
   ```
2. Open the project folder.
3. Double-click `index.html` to open it in your browser, or right-click it in VS Code and choose **Open with Live Server**.
